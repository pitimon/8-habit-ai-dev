# Installation

Choose your client and follow its canonical guide from installation through the first reviewed task. This page routes you to those guides; it does not duplicate their setup or update commands.

## Claude Code

[Claude Code guide](https://github.com/pitimon/8-habit-ai-dev/blob/main/docs/claude-code-integration.md): plugin installation, verification, namespaced skill invocation, session reminder and updates.

## Codex

[Codex guide](https://github.com/pitimon/8-habit-ai-dev/blob/main/docs/codex-integration.md): native plugin installation, skill selection/mentions, verification and marketplace/cache updates.

## Hermes Agent

[Hermes guide](https://github.com/pitimon/8-habit-ai-dev/blob/main/docs/hermes-integration.md): Skills Hub tap, individual skill installs, required category option, reference substitution and updates. Only skill content is installed; no runtime plugin manifest or Claude hooks travel with a tap install.

## OpenClaw

[OpenClaw guide](https://github.com/pitimon/8-habit-ai-dev/blob/main/docs/openclaw-integration.md): compatible bundle/workspace routes and verification boundaries. Real-install verification remains open in [#413](https://github.com/pitimon/8-habit-ai-dev/issues/413).

## Other agents

[Manual-loading guide](https://github.com/pitimon/8-habit-ai-dev/blob/main/docs/manual-integration.md): selecting and reading Markdown skills without assuming native package integration.
